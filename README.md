# bheliant

A 1:1 faithful clone of [ysuriadesign.co](https://ysuriadesign.co/) built with Next.js 16, React 19, Three.js r186, and custom GLSL shader pipelines.

## Features
- **WebGL 3D World**: Procedural monoliths, crystal refractions, instanced grass, particle dust, volumetric fog, and skinned figure model.
- **Audio Synthesizer Engine**: Procedural velocity-modulated sound effects (air, seam, rumble, stress, flutter) + background soundtrack crossfade.
- **Physics Virtual Scroll**: Momentum-driven spline camera navigation through 6 distinct chapters.
- **Interactive Work Modal**: High-definition video and interactive image showcases for P2P.org, Kelp DAO, RedStone, and LI.FI Jumper.
- **Comprehensive Quality Presets**: Support for `?q=low`, `?q=med`, `?q=high`, `?clean`, and `?perf`.
- **v1 Portfolio Route**: `/v1` classic portfolio.

## Getting Started
```bash
npm install
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the experience.
